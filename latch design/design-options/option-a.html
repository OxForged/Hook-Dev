02

What a Latch is

Definition

A hook contract attached to a pool

The pool key names a Latch in poolKey.hooks. At initialisation the pool manager calls getHooksRegistrationBitmap() on it and validates the answer with Hooks.validateHookConfig. From then on the Latch runs on exactly the callbacks its bitmap declares, and no others.

Custody never moves: a Latch accounts deltas against the Vault. With afterSwapReturnsDelta set it can take a bounded hookDelta — never more than the swap amount.

Capability bitmap · 14 bits · interactive

Registry reads it, you can too

bitmap0x0000·0example config

Registry

LatchRegistry · Sepolia

Lists Latches with curated metadata and the bitmap the contract itself reports. Reads are free: latchCount(), latchAt(i), getLatch(addr), listLatches().

0xB504da43C6ED342a511f3e5849f53035F2C807d1

A listing is not an audit. The registry states what the bitmap says and what it does not cover; nothing here says "safe".

03

Integration

solidity ^0.8typescript · viem
STEP 1
Deploy the Latch

No address mining. Unlike Uniswap v4, permissions come from getHooksRegistrationBitmap() on the contract, not from bits of its address.

STEP 2
Configure the pool

configure(key, params) claims the pool id for msg.sender before initialisation.

STEP 3
Initialise with hooks = Latch

Pool manager validates the bitmap. Wrong flags revert at init, not at the first swap.

STEP 4
Run the four calls

closeEpoch · rollover · settleBeneficiaries · applyPendingConfig. Permissionless. The keeper does it; anyone can.

SOLIDITY · script/ConfigureRevShare.s.solforge script
// SPDX-License-Identifier: GPL-2.0-or-later
pragma solidity ^0.8.26;

import {PoolKey} from "infinity-core/src/types/PoolKey.sol";
import {RevShareHook} from "../src/RevShareHook.sol";

contract ConfigureRevShare {
  function run(RevShareHook hook, PoolKey calldata key, address distributor) external {
    // take 0.3% of every swap, split 50 / 30 / 20 — must sum to SPLIT_DENOMINATOR
    hook.configure(key, RevShareHook.ConfigParams({
      feePips:        3_000,      // ≤ MAX_FEE_PIPS 100_000 (10%)
      lpDonateBps:    5_000,
      beneficiaryBps: 3_000,
      distributorBps: 2_000,      // Σ = 10_000
      distributor:    distributor,
      enabled:        true
    }));
    // after the pool is initialised, raising feePips goes through
    // proposeConfig → CONFIG_DELAY_BLOCKS → applyPendingConfig
  }
}
TYPESCRIPT · read.ts@latchprotocol/sdk
import { createPublicClient, http, parseAbi } from "viem";
import { sepolia } from "viem/chains";
import {
  registry, decodeCLHookPermissions, formatHookPermissions,
} from "@latchprotocol/sdk";

const client = createPublicClient({ chain: sepolia, transport: http() });
const REGISTRY = "0xB504da43C6ED342a511f3e5849f53035F2C807d1";

const count = await client.readContract({
  address: REGISTRY, abi: registry.RegistryAbis.Registry,
  functionName: "latchCount",
});
// the one function every Latch must answer — declared upstream in IHooks
const IHooksAbi = parseAbi(["function getHooksRegistrationBitmap() view returns (uint16)"]);

for (let i = 0n; i < count; i++) {
  const latch = await client.readContract({
    address: REGISTRY, abi: registry.RegistryAbis.Registry,
    functionName: "latchAt", args: [i],
  });
  // the bitmap the contract itself reports, not what the listing claims
  const bitmap = await client.readContract({
    address: latch, abi: IHooksAbi, functionName: "getHooksRegistrationBitmap",
  });
  console.log(latch, formatHookPermissions("CL", Number(bitmap)));
  const p = decodeCLHookPermissions(Number(bitmap));
  if (p.afterSwapReturnsDelta) console.log("may take a hookDelta on swap");
}

What you are trusting

Every token, every pool. Pool managers hold nothing. registerApp is onlyOwner and irreversible — there is no unregister.
