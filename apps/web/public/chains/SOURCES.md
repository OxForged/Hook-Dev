# Chain logo asset sources

All files below were downloaded as-is from the network's own website, its own asset
CDN, or its official GitHub organisation. Nothing here was drawn, traced, or
reconstructed by hand, and nothing came from a logo aggregator (CoinGecko, CMC,
cryptologos.cc, Brandfetch, etc.).

| Chain | File | Source URL | Notes |
| --- | --- | --- | --- |
| Ethereum | `ethereum.svg` | https://ethereum.org/images/assets/svgs/eth-diamond-purple.svg | Official ETH diamond from the ethereum.org brand assets page (https://ethereum.org/en/assets/). Multi-tone purple variant (`#8a92b2` / `#62688f` / `#454a75`). Sibling variants on the same path if a brighter mark is ever wanted: `eth-diamond-rainbow.svg`, `eth-diamond-glyph.svg`. |
| Base | `base.svg` | https://api.github.com/repos/base/brand-kit/git/blobs/9fc6d5b4af54d2ae658ddc5fa89b649898de5cc7 (blob `logo/in-product/Base_Network_Logo.svg` at commit `2798d3c` of https://github.com/base/brand-kit) | Official Base network mark: `#0052FF` circle with the white knockout. Taken from a pinned historical commit of Base's own brand-kit repo because current `main` replaced the symbol with "The Square" — a plain blue rounded rectangle with no mark inside it, which is unreadable as a chain icon. `raw.githubusercontent.com` 404s on that commit, so the GitHub blob API URL is the working permalink. |
| BNB Smart Chain | `bnb.svg` | https://www.bnbchain.org/images/brand-guidelines/svg/BNB%20Chain_Symbol_Yellow.svg | Official BNB Chain symbol served by bnbchain.org, linked from https://www.bnbchain.org/en/brand-guidelines. Brand yellow `#F0B90B`. |
| Linea | `linea.svg` | https://assets.ctfassets.net/64upluvbiuck/46y5rC2mj5Ocekur7vMSdP/c972526b87afa927a2e0bf2f506e8f75/Linea-Brand-Assets.zip → `Linea-Brand-Assets/Logo/SVG/Logomark White.svg` | Official Linea brand assets zip, the exact file behind the "Download brand assets" button on https://linea.build/assets, served from Linea's own Contentful CDN. Logomark (symbol), not the wordmark; the **White** variant because the brand's default logomark is near-black `#190066` and disappears on our dark surfaces. Black (`Logomark Black.svg`, `#121212`) and on-brand-background variants ship in the same zip, as do square/round LINEA token icons under `Token/`. 200×208. |
| Ink | `ink.svg` | https://docs.inkonchain.com/downloads/ink-logos.zip → `ink-logo-purple-white-icon.svg` | Official Ink logo pack, the exact file behind the "Download Logos" button on https://docs.inkonchain.com/work-with-ink/brand-kit. Icon (chain mark), not the wordmark. Chose the purple-with-white variant — solid Ink purple `#7132F5` disc with the mark knocked out in `#F0EFFF` — because the brand kit says to use Ink purple wherever possible and this is the one icon variant that carries its own background, so it reads on dark exactly as Base's does. The monochrome `ink-logo-light-icon.svg` / `ink-logo-dark-icon.svg` and gradient variants are in the same zip under `full set/`. 100×100. |
| X Layer | `xlayer.svg` | https://raw.githubusercontent.com/okx/xlayer-docs/main/media-kit/XLayer-logo-kit.zip → `XL/ICON/SVG/XLayer_Icon_WhenLessThan40px_White.svg` | Official X Layer media kit committed to OKX's own docs repo, https://github.com/okx/xlayer-docs (`media-kit/XLayer-logo-kit.zip`; the zip also carries `X Layer_Guideline.pdf`). OKX publishes no X Layer brand page on okx.com, and web3.okx.com/xlayer serves only raster CDN images — the repo is the authoritative source. Icon (symbol), not the `LOGO/` lockup. Picked the **WhenLessThan40px** simplification that the kit itself supplies for small rendering: it drops the 0.3-opacity blocks and the gradient of the full icon, which mush at the 18–40px we render at. White variant for dark surfaces; `XLayer_Icon_Black.svg` is the light-background sibling. 64×50, so it letterboxes inside the square box under `object-fit: contain`. |
| HyperEVM / Hyperliquid | `hyperevm.svg` | https://hyperliquid.gitbook.io/hyperliquid-docs/brand-kit → `Hyperliquid SVG format.zip` → `SVG/Hyperliquid_Blob_Green.svg` | Official Hyperliquid brand kit zip linked from the Hyperliquid docs. The "Blob" is the logomark; green (`#97fce4`) is the brand colour and the dark-background variant. White (`Hyperliquid_Blob_Light.svg`) is also in the zip. |
| Monad | `monad.svg` | https://www.monad.xyz/brand-page-assets/Logomark.svg | Official Monad logomark, the exact file served by the Download button on https://www.monad.xyz/brand-and-media-kit. Purple `#6E54FF`. |

| Stable | `stable.svg` | https://stable.xyz/brand/logo/stable-logotype-light.svg | Official Stable logomark (the "S" ribbon), light variant `#E8FBF7`, from the stable.xyz brand kit at https://www.stable.xyz/brand-kit.
